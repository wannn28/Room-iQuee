# Aruna — konfigurator perangkat rumah

Demo satu halaman untuk memasang perangkat di ruang kosong. Bahasa Indonesia. Bukan toko, tanpa keranjang, tanpa backend, tanpa database.

## Alur

1. **Lampu** — satu lampu plafon; hanya menempel di langit-langit. Klik permukaan lain diabaikan.
2. **Keamanan** — satu kamera; hanya menempel di dinding. Klik permukaan lain diabaikan.
3. Rak bawah (HTML): dari **82%** tinggi viewport sampai tepi bawah, lebar penuh. Kiri = nama langkah, tengah = perangkat langkah itu (bukan deretan pilihan), kanan = **Lanjut** / **Selesai**.

## Stack

- Next.js
- TypeScript
- React Three Fiber
- `@react-three/drei`
- Three.js

## Menjalankan

```bash
npm install
npm run dev
npm run build
npm start
```

Tidak ada deploy dari repo ini. DNS dan repositori lain tidak disentuh.
